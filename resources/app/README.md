## 🛠️ Installation Instructions (Important!)

Because this game is built using the Electron runtime, Electron will load `App.asar` by default unless it is renamed. Please follow these steps to install the English patch:

### Step 1: Rename `App.asar`
1. Open your game root folder (`遥かなるセレスフィアv2.0`).
2. Navigate into the `resources/` folder.
3. Locate **`App.asar`** (or `app.asar`) and rename it to **`App.asar.bak`** (or `App.asar.disabled`).

### Step 2: Apply the Patch
* **Automatic (Using Updater)**:
  Run **`GameUpdate.bat`** in your game root folder to automatically fetch and apply the latest English translation patch.
* **Manual**:
  Extract the patch zip so that the `resources/app/` folder sits inside your game's `resources/` directory (i.e. `resources/app/data/`, `resources/app/js/`, etc.).

### Step 3: Verify Patch Loading
1. Launch **`Game.exe`**.
2. On initial launch, you should see the **English Translation Patch Splash Screen** crediting Linandino.
3. Start a **New Game** — you will see the English welcome message box confirming the patch is loaded.
4. Check the Title Menu for the **"Support Translator (Ko-Fi)"** button.
