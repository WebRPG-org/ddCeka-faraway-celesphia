## 🌟 About This Translation Patch

This is the complete English translation patch for **Faraway Selesphia v2.0.0** (*遥かなるセレスフィア v2.0*).

### ✨ Features Added in Patch:
1. **Full English Localization**: All dialogues, quest logs, menus, item descriptions, and bestiary entries translated into English.
2. **Bootup Credits Splash Screen**: Custom splash screen on boot displaying patch information and support links.
3. **Title Screen Integration**: Direct "Support Translator (Ko-Fi)" menu command on the title screen.
4. **Universal Electron / Web Support**: External links open seamlessly in Electron desktop builds or default browsers.
